# BHURAKSHA

AI-Powered Landslide Early Warning & Risk Management System for North Eastern India.

Prototype for SIH26001 (MDoNER) — **Prototype • Simulated Data**.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (default http://localhost:5173).
